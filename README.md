# MeetingMind

Monorepo cho MeetingMind (MVP) — chứa frontend, backend, AI workers và infra helper.

Xem sơ đồ kiến trúc chi tiết: [ARCHITECTURE.md](ARCHITECTURE.md)

Thao tác nhanh cho dev local:

1. Cài Docker & Docker Compose
2. Vào `infrastructure/` và chạy `docker compose -f docker-compose.dev.yml up`
3. Chạy service dev từng phần (xem README mỗi service)

Tiếp theo tôi có thể scaffold README/Dockerfile cơ bản cho từng service nếu bạn muốn.
